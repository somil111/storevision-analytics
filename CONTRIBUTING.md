# Contributing to StoreVision Analytics Platform

Thank you for your interest in contributing! We welcome contributions from the community.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Create a new branch for your changes
4. Make your changes
5. Submit a pull request

## Development Setup

```bash
git clone https://github.com/yourusername/storevision-analytics.git
cd storevision-analytics

python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

cd backend
pip install -r requirements.txt
```

## Code Style

- Follow PEP 8 conventions
- Use type hints for function parameters and returns
- Write descriptive docstrings
- Keep functions focused and modular
- No emojis in code comments

## Testing

Run tests before submitting PRs:

```bash
pytest backend/tests/
```

## Reporting Issues

When reporting issues, please include:
- Python version
- Operating system
- Steps to reproduce
- Expected vs actual behavior
- Error messages/logs

## Feature Requests

Feature requests are welcome. Please describe:
- What you want to build
- Why it would be useful
- Potential implementation approach

## Pull Request Process

1. Update README.md if needed
2. Follow the code style guidelines
3. Ensure all tests pass
4. Provide clear PR description
5. Reference related issues

## Areas for Contribution

- Bug fixes
- Performance optimization
- Enhanced classification algorithms
- Better tracking methods
- Documentation improvements
- Test coverage
- UI/UX enhancements

## Questions?

Open an issue or contact the maintainers.

Thank you for contributing to StoreVision!
