HOW USERS ACCESS THE WEBSITE
================================================================================

OPTION 1: LOCAL SETUP (Developers)
  1. Clone: git clone https://github.com/yourusername/storevision-analytics.git
  2. Install: pip install -r backend/requirements.txt
  3. Run: python backend/main.py
  4. Open: http://localhost:8000/static/index.html

OPTION 2: DOCKER (Easy Deploy)
  1. Clone repository
  2. Run: docker-compose up --build
  3. Open: http://localhost:8000/static/index.html

OPTION 3: CLOUD (For Public Access)
  • Deploy to Heroku, AWS, GCP, or DigitalOcean
  • Instructions in DEPLOYMENT.md
  • Share public URL with users

OPTION 4: BATCH SCRIPT (Windows Users)
  1. Clone repository
  2. Double-click: START_SERVER.bat
  3. Browser opens automatically
